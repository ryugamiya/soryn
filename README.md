# SORYN（ソリン）

SORYN の経営ダッシュボードへの入口ページです。
iPhone のホーム画面や MacBook の Dock に「SORYN」の名前とアイコンで追加するためだけのページで、
経営情報は一切置いていません（記録は claude.ai の非公開ページにあり、持ち主だけが見られます）。

- 公開先：https://ryugamiya.github.io/soryn/
- 使い方：iPhone は Safari の共有ボタン →「ホーム画面に追加」、Mac は Safari の「ファイル」→「Dockに追加」
- ロゴは採用済みデザインを形・比率を変えずに縮小・配置したものです
